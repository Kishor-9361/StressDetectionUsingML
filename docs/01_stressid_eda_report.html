Operational Decisions

Actionable Decisions for Phase 3 (Dashboard) & Phase 4 (Modeling)

1
Window Size Standardization: 60-second Windows

Within-task dynamic analysis shows that heart rate and HRV measures remain temporally stable across consecutive 60s sub-windows (30s stride) in long tasks (Breathing subwindows stabilize around z ~= 0.0), while interactive tasks exhibit acute arousal. We standardize on 60s windows for all modeling.

2
Signal Quality Triage Gate: Mandatory q_eda > 0 Filter

Sensor saturation was isolated to participant r5s8 during Counting3 (variance = 0, EDA railed at 65535). A mandatory quality filter (q_eda > 0 and q_ecg ≥ 0.5) retains 97.83% of windows while dropping zero valid subject sessions.

3
Respiration Calibration Anchor: Relax Task Only

The calm breathing exercise task deliberately paces respiration rate. Respiration features MUST remain anchored against the Relax task, never Breathing, to prevent normalizing away physiological stress reactivity.

4
Dashboard Priority: Implement Page 3 (Label Validity & Effect Sizes) First

Per-subject Cohen's d analysis reveals that exactly 10 subjects exhibit low or paradoxical physiological reactivity (d < 0.2) to cognitive stressors. Page 3 is prioritized to allow interactive inspection of low-reactor response curves rather than blind row deletion.
